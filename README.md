# 📊 Smart Analytics Dashboard

## 📌 Project Overview

Smart Analytics Dashboard is a web-based data analytics application developed using Python Flask, HTML, CSS, Pandas, and JavaScript.

This application allows users to upload CSV datasets, analyze important data metrics, and visualize data through interactive charts.

## 🚀 Features

- CSV Dataset Upload
- Automatic Data Analysis
- Total Records Calculation
- Total Columns Detection
- Numeric Columns Identification
- Data Visualization using Bar Charts
- Dataset Preview
- Responsive User Interface
- Modern Dashboard Design

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- HTML5
- CSS3
- JavaScript
- Chart.js

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to Project Folder

```bash
cd Smart_Analytics
```

### Step 3: Install Dependencies

```bash
pip install flask pandas
```

### Step 4: Run the Application

```bash
python server.py
```

### Step 5: Open in Browser

```text
http://127.0.0.1:5000
```

## 📈 How It Works

1. Open the Smart Analytics application.
2. Navigate to the Analytics Dashboard.
3. Upload a CSV dataset.
4. Click the Analyze Dataset button.
5. View dataset statistics.
6. Explore the generated bar chart.
7. Preview the uploaded dataset.

## 🎯 Project Objective

The main objective of this project is to develop a simple and responsive data analytics application that helps users understand datasets through automated analysis and visual representation.
